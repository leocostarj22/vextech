# Fotos dos trabalhos

Todas geradas para a marca fictícia (sem marca real). Proporção em `pecas.json` (w × h em px).

| Arquivo | O que mostra |
|---|---|
| torra-alta.webp | Destaque 1: sacos de café Torra Alta (verde e kraft) num parapeito de concreto, 1536×1024 |
| sol.webp | Destaque 2: caixa com "sól" em relevo e dois copos de cerâmica, 1536×1024 |
| restinga.webp | Destaque 3: livros verdes em tecido da editora Restinga numa prateleira, 1536×1024 |
| preamar.webp | Destaque 4: celular com o app de marés Preamar e um cartão com a marca, 1536×1024 |
| t01–t04 | cartaz de arcos no concreto, placa redonda, cartaz terracota, sacola de lona |
| t05–t08 | frasco âmbar, cadeira de madeira, cardápio preto, cartaz do galo |
| t09–t12 | cartões de visita, garrafa de cachaça, fachada de ripas, cadernos |
| t13–t16 | lona com folha num prédio, livro aberto com mar, caneca com sol, sacola de papel |
| t17–t20 | cartaz de festival, app de comida, etiquetas, pote de mel |
| t21–t24 | placa esmaltada, camisetas, capa de revista, vaso com folha |
| t25–t28 | mural de café, papelaria, sabonete, ingresso de cinema |
| metodo-rascunho.webp | Método 1: rascunho a lápis da marca da Torra Alta em papel manteiga (retrato) |
| metodo-sistema.webp | Método 3: prancha do sistema (cores, padrões, etiquetas) (retrato) |
| metodo-rua.webp | Método 4: o saco de café recortado do destaque (retrato) |

Para trocar pelas fotos do seu estúdio: mantenha os nomes ou atualize `pecas.json` (id, src, w, h). As do túnel ficam bem entre 700 e 800 px no lado maior; as de destaque com 1500 px ou mais, em paisagem 3:2. Para gerar mais na mesma linha, use o parágrafo de `estilo-das-fotos.txt`.
